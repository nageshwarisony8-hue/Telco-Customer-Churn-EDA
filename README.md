# Telco Customer Churn – EDA

## 📌 Project Overview
Exploratory Data Analysis of the Telco Customer Churn dataset using Python to identify customer churn patterns and generate business insights.

## 🎯 Objectives
- Analyze customer churn patterns
- Understand customer demographics, services, contracts and charges
- Identify factors associated with churn
- Create meaningful visualizations and pivot tables
- Generate business insights

## 📊 Dataset
- **Source:** Kaggle
- **Rows:** 7,043
- **Columns:** 21
- **Target:** Churn (Yes/No)

## 🧹 Data Preparation
- Handled 11 missing values in `totalcharges`
- Checked duplicate records
- Applied IQR method for outlier detection
- Analyzed class imbalance

## 🔍 EDA
Performed:
- Univariate Analysis
- Bivariate Analysis
- Multivariate Analysis
- Pivot Tables
- Data Visualizations

## 💡 Key Insights
- Month-to-month customers show higher churn.
- Shorter-tenure customers are more likely to churn.
- Fiber optic customers show higher churn.
- Electronic check users show higher churn.
- Higher monthly charges are generally associated with higher churn.
